# 🚀 LaunchReady - מערכת בדיקת מוכנות אתר למסירה ללקוח & דוח משימות (TODO)

מערכת Web מתקדמת המבצעת סריקת QA מקיפה לאתר לפני מסירתו ללקוח. המערכת מאתרת קישורים שבורים, תמונות חסרות או ללא תיאור, בעיות נגישות קריטיות, תגיות SEO חסרות או חוסמות, שאריות מלל דמה (Lorem Ipsum), ומפיקה **דוח אינטראקטיבי ורשימת משימות TODO לתיקון**.

---

## 🔍 מה המערכת בודקת?

1. **🔗 קישורים (Links Audit):**
   - איתור קישורים שבורים בזמן אמת (שגיאות 404, 500, שגיאות רשת ופסק זמן).
   - קישורים ריקים (`href=""`) או פלייסהולדרים (`#`, `javascript:void(0)`).
   - קישורים המכילים דומיין פיתוח/Staging שנשכח (כגון `staging.domain.com` או `localhost`).
   - אבטחת קישורים חיצוניים (`target="_blank"` ללא `rel="noopener noreferrer"`).
   - קישורי טלפון ואימייל תקינים.
   - טקסט עוגן עמום הפוגע ב-SEO ובנגישות ("לחץ כאן", "קרא עוד").

2. **🖼️ תמונות ומדיה (Images Audit):**
   - תמונות שבורות שאינן נטענות.
   - תמונות חסרות תגית `alt` (פגיעה קשה בנגישות וב-SEO).
   - תגיות `alt` סתמיות או שמות קבצים (כגון `alt="image"` או `alt="logo.png"`).
   - תמונות ללא הגדרת רוחב וגובה מפורשים (`width` / `height` למניעת קפיצות בדף - CLS).
   - בדיקת הימצאות אייקון אתר בדפדפן (**Favicon**).
   - אזהרה על תמונות כבדות במיוחד מעל 1MB או פורמטים מיושנים.

3. **♿ נגישות (Accessibility - WCAG 2.1):**
   - הגדרת שפת מסמך בתגית `<html>` (קריטי לקוראי מסך בעברית/אנגלית).
   - היררכיית כותרות מלאה (`<h1>` יחיד וברור, איתור דילוגים בין רמות כגון H1 ישירות ל-H3).
   - שדות טפסים ללא תווית `<label>` או `aria-label`.
   - כפתורים ללא טקסט או שם נגיש (כפתורי אייקון).
   - אזורי ציון סמנטיים (`<main>`, `<header>`, `<nav>`, `<footer>`).
   - ביטול זום במובייל (`user-scalable=no` או `maximum-scale=1` - תקלת נגישות חמורה).

4. **🔍 SEO ומבנה טכני:**
   - תגית `<title>` – בדיקת קיום, אורך אופטימלי (30-60 תווים), ומניעת כותרות ברירת מחדל ("דף הבית", "Untitled").
   - תגית `<meta name="description">` – קיום ואורך מומלץ.
   - תגית התאמה למובייל (`<meta name="viewport">`).
   - תגית קנונית (`<link rel="canonical">`).
   - **🚨 אזהרת noindex קריטית:** התרעה אם תגית ה-Robots חוסמת את האתר מאינדוקס בגוגל (תקלה קלאסית במעבר מפיתוח לפרודקשן!).
   - תגיות Open Graph לשיתוף בוואטסאפ ופייסבוק (`og:title`, `og:image`, `og:description`).
   - בדיקת קיום קובצי `robots.txt` ו-`sitemap.xml`.

5. **🛡️ אבטחה ושאריות פיתוח (Hygiene):**
   - פרוטוקול מאובטח (HTTPS) ובדיקת Mixed Content.
   - כותרות אבטחה בסיסיות (HSTS, X-Frame-Options, X-Content-Type-Options).
   - איתור מלל דמה **Lorem Ipsum** שנשכח באתר.
   - איתור אימיילים ומספרי טלפון לדוגמה (`test@test.com`, `123456789`).
   - איתור פקודות דיבאג שנשכחו בקוד (`debugger;`, `console.log`).

## 💻 כיצד להפעיל את המערכת?

### אפשרות 1: הרצה בלחיצה אחת (Windows)
לחץ לחיצה כפולה על הקובץ:
```
run.bat
```

### אפשרות 2: דרך הטרמינל
```bash
python -m uvicorn main:app --host 127.0.0.1 --port 8080
```

לאחר ההפעלה, פתח את הדפדפן בכתובת:
👉 **[http://127.0.0.1:8080](http://127.0.0.1:8080)**
